# Safe Anchor

2D 俯视角空间规划解谜游戏。投掷锚点铺设安全路径，引导难民沿锚链走向安全屋。

**引擎**: Godot 4.7 | **分辨率**: 1920×1080 | **语言**: GDScript

---

## 玩法

- 观察关卡 → 投掷锚点 → 难民沿锚链移动 → 到达安全屋
- 锚点有不同类型：普通锚点、大型锚点、驱赶锚点
- 躲避岩浆和危险区，利用矿车接住锚点

## 操作

| 按键 | 功能 |
|------|------|
| WASD | 移动 |
| 鼠标左键按住/松开 | 蓄力投掷锚点 |
| K | 调试跳关 |

## 关卡

| # | 名称 | 特色 |
|---|------|------|
| 1 | 新手关 | 入门教学 |
| 2 | 过桥 | 锚点限制，分散难民 |
| 3 | 矿车 | 矿车接锚 |
| 4 | 飞屋 | 安全屋偏移，高难度 |
| 5 | 反向锚1 | 驱赶锚点入门 |
| 6 | 反向锚2 | 大量驱赶锚点 |

## 运行

1. 用 Godot 4.7 打开 `project.godot`
2. 按 F5 运行

## 项目结构

```
src/
├── main/        # 主入口
├── autoload/    # GameManager 单例
├── player/      # 玩家
├── refugee/     # 难民 AI
├── anchor/      # 锚点 + 岩浆
├── safe_house/  # 安全屋
├── world/       # 世界容器 + 关卡编辑器
└── ui/          # 界面
resources/levels/  # 关卡数据
assets/sprites/    # 素材
```
